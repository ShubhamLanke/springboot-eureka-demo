# springboot-eureka-demo

A demo project to demonstrate inter-service communication between Order Service and User Service using Spring Boot, Spring Cloud Eureka Server, and RestTemplate.

**This project contains:**
A Eureka Server for service registration and discovery.
A User Service that communicates with the Order Service.
An Order Service that provides order details for a given user.

**🔧 Technologies Used**
Java 17+
Spring Boot
Spring Cloud Netflix Eureka
RestTemplate (for service-to-service communication)
Maven
